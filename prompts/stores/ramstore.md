# ramstore source naming

Names and product categories are mainly Cyrillic. Readable fields retain their meaning and preserve legitimate foreign brands. Backticks in Ф`СТАЦИ, `РЃА and А`ЃУПКА represent apostrophes, not ж. Brand can precede product type; preserve explicit variety, quantity and pack. Supporting quotes must copy the original fields.

Only apply a naming convention when product context supports it. A source code is not a barcode or product size unless identified as such.
