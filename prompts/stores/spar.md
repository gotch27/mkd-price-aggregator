# spar source naming

The application supplies readable_name and, when necessary, readable_description/readable_category. Prefer these for understanding; name/description/category remain the exact source for supporting quotes. Do not decode readable text again.
Names use Macedonian JUS character positions: [ = ш, ^ = ч, @ = ж, ] = ќ, backslash = ѓ, Q = љ, W = њ, X = џ and Y = ѕ in encoded words. Examples: SIREWE means сирење; [OQA means шоља. Genuine English words, brands, sizes (XL), watts (W), quantities and model codes are preserved by code. Never blindly replace every Q/W/X/Y yourself.
Store categories include "Te pa specifikuara" (unspecified) and inaccurate English translations. Infer the category from the product name and supported details, not that translation. N/1 can state a pack count. H between two numbers can represent multiplication only when the full wording clearly describes a multipack; dimensions and model codes are not pack counts.

Only apply a naming convention when product context supports it. A source code is not a barcode or product size unless identified as such.
