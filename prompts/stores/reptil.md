# reptil source naming

Names use genuine Latin brands plus Cyrillic descriptions, separated by a dash. These are not legacy keyboard text: do not transliterate the brand or model. The readable fields only clean formatting. ref.kg describes a loose sale unit, not a fixed one-kilogram package. Long descriptions can contain nutritional amounts that are not the pack size. Supporting quotes must copy original fields.

Only apply a naming convention when product context supports it. A source code is not a barcode or product size unless identified as such.
