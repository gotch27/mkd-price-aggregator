# vero source naming

Most names are already Cyrillic; a smaller subset uses the same legacy character positions as SPAR. The readable fields decode recognized words. Genuine Latin brands and article/model codes remain unchanged. Backticks in Cyrillic brand names such as Д`ОРО are apostrophes, not ж. Keep alcohol percentage, volume, brand and gift accessories separate. Original fields, not readable fields, supply literal supporting quotes.

Only apply a naming convention when product context supports it. A source code is not a barcode or product size unless identified as such.
