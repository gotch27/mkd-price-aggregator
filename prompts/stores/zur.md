# zur source naming

Names are mainly Cyrillic with leftover legacy glyphs repaired in readable fields: ПЛА`А means ПЛАЖА and ЦВЕ}Е means ЦВЕЌЕ. Brand can occur at the end. N/1 can describe a pack count. Question marks come from the source and must not be guessed into letters. Preserve article/model codes and distinguish size from count. Literal supporting quotes must come from original fields, not the readable version.

Only apply a naming convention when product context supports it. A source code is not a barcode or product size unless identified as such.
