# stokomak source naming

Names and categories are primarily clean Cyrillic. Keep brand/model spellings and printed units intact; do not apply SPAR character decoding. Preserve fruit variety, grade and decimal weight separately. Loose goods sold by kg are not fixed one-kilogram packs. Product names and categories can disagree; do not replace a specific name with a broad category. Use original fields for literal supporting quotes.

Only apply a naming convention when product context supports it. A source code is not a barcode or product size unless identified as such.
