# dim source naming

Names are mainly Cyrillic with leftover legacy glyphs: `ЕНСКИ means ЖЕНСКИ, СВЕ]А means СВЕЌА and ЦВЕ}Е means ЦВЕЌЕ. The readable fields repair these. A standalone backtick may be a female marker. Apostrophes in Ф`СТАЦИ remain apostrophes. Source question marks may be damaged punctuation; do not invent a replacement letter or absent fact. Separate diaper count, diaper size and baby weight range. N/1 can describe a count, never grams. Supporting quotes must use the original fields.

Only apply a naming convention when product context supports it. A source code is not a barcode or product size unless identified as such.
